# Manfred von Karma AO3 Site Skin
A site skin for the website 'Archive Of Our Own'. Site skins are a neat tool that allows AO3 users to tailor the site more to their liking. I made this one based on the Ace Attorney character Manfred von Karma.
# How to activate a site skin!
1. Copy the code that you can find in the code section of this page
2. Go on the website https://archiveofourown.org
3. Select the 'Skins' tab
4. Select the 'Create Site Skin' button
5. Name it whatever you would like and paste the code into the section asking for the CSS
6. Click the 'Submit' button at the bottom of the page
7. Enjoy!
The skin features custom icons, kudos messages, a highlight on tags featuring Manfred's name, and more!
